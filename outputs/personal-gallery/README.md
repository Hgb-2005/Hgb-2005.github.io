# 郝贵彬的个人作品展览馆

按参考作品集的暗色、微光和沉浸感制作，包含动态星球入口、作品展位、实时游戏展台、个人介绍和可开关的环境音。已经接入你的真实游戏「微光球场 · ORBIT」，也保留 GitHub 源码入口。

## 当前展品 v0.10.0

更新于 2026-10-26：2v2 团队、手机摇杆、3 / 5 / 8 分钟房间规则、联机同步优化。展台使用新版实际游戏截图；游戏源码与发布标签一致，本机支持直接试玩，GitHub 网页版提供完整游戏下载入口。

## 第二版体验

- 三幕滚动序厅：微光树林 → HGB 立体粒子署名 → 发光入口环，滚动控制变形；章节可直接跳转，也能跳过序厅。
- 空间感互动：微光跟随鼠标、粒子响应指针、封面轻微倾斜、悬停光线与固定楼层导航。
- 双栏作品展台：大画面实时预览与创作介绍并列；可以在展厅内试玩真实游戏，或在独立窗口游玩。结束试玩会重新准备游戏，关闭展台后释放游戏页面。
- 创作记录：呈现作品的想法、体验与联机功能，围绕你的真实游戏编排。
- 手机与键盘适配：小屏幕展台上下排列，详情区可滚动；支持关闭按钮和 Esc；减少动态效果时，三幕文案展开阅读。
- 动效可暂停，选择保存在浏览器；环境音需点击开启，进入游戏试玩时自动关闭。背景页与屏幕外的序厅会停止计算动画。

## 在这台电脑上打开

双击 start.bat，会自动打开预览。保持启动窗口运行；也可手动访问 http://127.0.0.1:8766/ 。

首次启动需要安装 Python 3.9 或以上。启动脚本会优先使用本机已有的 Anaconda Python，再尝试系统 Python，创建项目专用的 .venv 环境并安装依赖。也可手动依次运行：

    python -m venv .venv
    .venv\Scripts\python.exe -m pip install -r requirements.txt
    .venv\Scripts\python.exe app.py

游戏入口：http://127.0.0.1:8766/play/ 。

这是本机试玩地址。作品集网页版：https://hgb-2005.github.io/ ，展示新版介绍与游戏下载入口；网页版不运行 Flask 游戏。本机服务停止后，本机地址会失效。不要直接双击 index.html 试玩游戏。

## 内容在哪里修改

- assets/content.js：姓名、项目名称、项目描述、GitHub 与游戏链接。
- index.html：完整文案、介绍、展位和详情内容。
- assets/style.css：配色、字体、布局和手机适配。
- assets/gallery.js：粒子、动态球体、封面、环境音和交互。
- assets/immersive.js 与 immersive.css：三幕序厅、景深、动效暂停、楼层导航和实时作品展台。
- assets/orbit-preview.webp：从你的真实游戏截取的预览画面。
- game/：现有游戏的源码副本，保留单机、联机、分数 API 与规则。
- app.py：把展览馆和真实游戏放在同一个 Flask 服务里。

交付包使用自己的 instance/game.sqlite3。首次运行自动生成，不会改动你原游戏的数据库。内置游戏与 Hgb-2005/orbit-game 的 v0.10.0 发布标签一致，提交与文件清单记录在 orbit-version.json。

## GitHub 网页版

仓库中的 tools/build-pages.py 生成静态展览馆，部署时将 assets/deployment.js 设置为网页版模式：展示新版本截图，按钮指向游戏发布页，隐藏需要 Flask 的展厅内试玩。GitHub Pages 不能运行 Flask 游戏；本机版继续保留试玩。

若希望展览馆和游戏一起运行，需要支持 Python、Flask、WebSocket 和持久化存储的服务。当前 app.py 启动方式用于本机预览；公网部署应配置生产服务和数据库持久化。

本版不需要前端打包、不依赖远程字体或图片。粒子与封面由代码生成；环境音由 Web Audio 合成，点击后才播放。
